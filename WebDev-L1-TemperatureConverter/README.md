# Temperature Converter

## OASIS INFOBYTE - Web Development & Designing

### Task 3: Temperature Converter

This project is a temperature converter web application developed using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Numeric input validation
- Conversion button
- Displays the converted temperature with unit labels
- Handles invalid temperature values
- Clean and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the `index.html` file in a web browser.
3. Enter a temperature.
4. Select the required unit.
5. Click the Convert button.
